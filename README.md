# Assets

A repository for genuine, reusable asset files, grouped by project with source, rights and file metadata documented alongside the binaries. The repository's existing root [`LICENSE`](LICENSE) is preserved. Assets with their own third-party license retain those distinct terms in their project folder; the repository license is not a substitute for source attribution.

## Horizon Drive

The initial published asset set for **Horizon Drive**, a Three.js forest-road driving game, is in [`HorizonDrive/`](HorizonDrive/README.md). It contains the generated sports coupe and broadleaf tree GLBs; the original downloadable Poly Haven/AmbientCG PBR/HDRI files; optimized 512px texture variants for phones; a lightweight browser environment derivative; and game branding artwork. None of the promo art is an in-game 3D model or texture.

- [Browse the game asset guide](HorizonDrive/README.md)
- [Read source and licensing notes](HorizonDrive/SOURCES_AND_LICENSES.md)
- [Per-file SHA-256, license and verified direct-download manifest](HorizonDrive/ASSET_MANIFEST.json)

New projects should use their own folder and preserve a file-level source/license record. Avoid committing secrets or downloaded media without a valid redistribution basis.
